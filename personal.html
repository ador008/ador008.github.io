MSc courses

Aalborg University Copenhagen, by semester.

1st semester

  • Fundamentals of CryptographyThe building blocks of secure communication: symmetric and public-key encryption, hash functions and digital signatures. How these tools work, and how to use them correctly.
  • Network SecurityHow attackers target networks, and how to defend them. Covers secure protocols, firewalls, intrusion detection and building secure network designs.
  • Internet of Things (IoT)How connected devices and sensors work together, and the security and privacy challenges that come with small, resource-limited devices.

2nd semester

  • Software SecurityFinding and preventing security flaws in software, such as memory errors and injection attacks. Secure coding practices and testing to catch weaknesses early.
  • Hacker SpaceA hands-on course in practical security: working on real security challenges and learning to think like an attacker in order to defend systems better.
  • Identity and Access ManagementHow organisations control who can access what. Covers authentication, authorization, single sign-on and managing user identities securely.

3rd semester

  • Advanced CybersecurityDeeper study of current security threats and defences, building on earlier courses with more complex attacks and protection methods.
  • Enterprise SecurityProtecting a whole organisation: security management, risk assessment, policies and how security fits into business operations.
  • Privacy EngineeringBuilding privacy into systems from the start: protecting personal data, privacy-enhancing technologies and data protection rules such as the GDPR.

4th semester

  • Master's thesis (in progress)
